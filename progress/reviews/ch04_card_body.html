② 数学思想与作者核心观点

McElreath 在第4章想让你接受的比公式更重要的"为什么"——每条可追溯原文。

线性模型是地心模型（Geocentric Model） — "Linear regression is the geocentric model of applied statistics… it can usefully describe a very large variety of natural phenomena… if we read its structure too literally, we're likely to make mistakes." 描述有用，解释危险；拟合好不等于因果对。 §4.0, p84
高斯的两类辩护 — 本体论（ontological）：物理加法机制产生高斯（CLT）；认识论（epistemological）：仅知均值/方差时，高斯是最大熵、最保守的选择。两种理由都合法，适用场景不同。 §4.1.4, p88–89
先验是模型的一部分，不是负担 — "There is no more a uniquely correct prior than there is a uniquely correct likelihood." 先验编码看数据前的知识状态；选先验就是做模型决策，应当讨论和探索，而非回避。 §4.4.1.2, p108
i.i.d. 是认识论假设，不是本体论声明 — "not a claim that these people are actually independent… It is instead an epistemological assumption." 独立同分布是"对相关性一无所知"的保守表达，不是对世界的断言。违反不一定有大问题，但要清楚自己在做什么。 §4.3.2, p94
多项式：用之有益，信之危险 — "We should feel embarrassed to use them, just so we don't become satisfied with the phenomenological explanations they provide." 多项式是地心模型的极致：拟合能力强但解释危险，且外推失控。Better would be a mechanistic model with theoretical grounding. §4.5, p123–125

关键数学思想

  • 对数后验 ≈ 抛物线，高斯的对数精确等于抛物线：MAP 二次近似的核心——对数后验在峰附近做二阶泰勒展开得抛物线（这步是近似），而高斯的对数本身就精确是抛物线，所以高斯近似后验本身。近似对象是对数后验，不是高斯函数。
  • Hessian = 多维曲率的压缩编码：1D 时 σ² = 1/|f''|；2D 时 Hessian 的逆 = 协方差矩阵。混合偏导 ≠ 0 ↔ 等高线倾斜 ↔ 参数后验相关。
  • MAP 跳过积分的形式理由：分母 P(data) 对所有 θ 是常数，argmax 时直接丢弃；预测变量的先验 P(x) 也因同理自动消去（只要 P(x) 不含模型参数）。
  • 标准化让优化地形条件数趋 1：不标准化时 w² 可达 3600，Hessian 条件数 κ ≈ 10⁷，导致 catastrophic cancellation + zigzag 收敛；标准化后 ws² 约 0–4，κ ≈ 1，BFGS 快速收敛。

③ 核心概念与公式

CLT intuition — 大量独立随机量相加，波动互相抵消，落在均值的路径最多 → 钟形。与分叉路径花园同构（"最多路径"）。
§4.1.1, p85–87
模型规范语言 — ~ 随机关系（服从分布）；= 确定关系（由其他量完全决定）。μ_i = α+β·x 用等号，μ_i 无先验。
§4.2, p90–91
联合后验 joint posterior — Pr(μ,σ|h)：(μ,σ) 的联合分布，对应无数条可能的高斯分布。热力图可视化峰位与形状。
§4.3.2, p92
MAP 二次近似 quap — minimize(neg_log_post) 找峰；四点差分数值 Hessian → cov=inv(H)；multivariate_normal 采样(μ,log_σ)，exp 还原 σ。
§4.3.5–4.3.6, p99–103
线性模型策略 — μ_i = α + β·x_i（确定关系 =）；先验只加参数(α,β,σ)；预测变量 x 是数据，其先验自动在后验中消去。
§4.4.1, p105–107
中心化 centering — x_c = x − mean(x)；使 α 可解释（= 均值体重处期望身高）；消除 α-β 高度负相关，数值更稳。
§4.4.3.1, p112–113
两类不确定性 — 均值 HPDI（参数 α,β 后验 → 窄）vs 预测 PI（参数+σ随机性 → 宽）。HPDI 不是"实际值落点"。
§4.4.3.4–5, p115–122
标准化 standardizing — ws = (w−mean)/std；ws² 不爆炸；β 解释为"每增 1 SD 对应的变化"，多变量可横向比较。
§4.5, p124–125
log posterior ≈ parabola (Taylor) → exp → Gaussian approximates posterior
MAP: argmax[log P(data|θ) + log P(θ)] (denominator P(data) = constant, dropped)

Cov = inv(H_neg_log_post) at MAP
SE(σ) = SE(log_σ) × σ (delta method)

mu_mat[:,i] = a_samp + b_samp * w_seq[i] → HPDI = percentile(mu_mat, [5.5,94.5], axis=0)
PI: h_sim = rng.normal(mu_mat, sigma_samp[:,None]) → percentile(h_sim, ...)

# §4.3b — MAP + 数值Hessian + 后验采样
def neg_log_post(params):
    mu, log_sigma = params
    sigma = np.exp(log_sigma)
    ll = np.sum(stats.norm.logpdf(heights, mu, sigma))
    return -(ll + stats.norm.logpdf(mu, 178, 20))

res = minimize(neg_log_post, [170, np.log(8)], method='BFGS')
eps = 1e-4; H = np.zeros((2,2))
for i in range(2):
    for j in range(2):
        xpp=res.x.copy(); xpp[i]+=eps; xpp[j]+=eps
        xpm=res.x.copy(); xpm[i]+=eps; xpm[j]-=eps
        xmp=res.x.copy(); xmp[i]-=eps; xmp[j]+=eps
        xmm=res.x.copy(); xmm[i]-=eps; xmm[j]-=eps
        H[i,j]=(neg_log_post(xpp)-neg_log_post(xpm)
                -neg_log_post(xmp)+neg_log_post(xmm))/(4*eps**2)
cov = np.linalg.inv(H)
samp = rng.multivariate_normal(res.x, cov, 10000)
post = np.column_stack([samp[:,0], np.exp(samp[:,1])])   # (μ, σ)
